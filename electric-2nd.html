Claude 응답: 사진의 도면 목록에는 도면 이름만 있고 장비 정보(용량, 수량 등)는 없어요.

메모리 업데이트됨electrical-equipment-schedule.md

사진의 도면 목록에는 도면 이름만 있고 장비 정보(용량, 수량 등)는 없어요. 그래서 목록은 "어느 도면을 봐야 하는지" 찾는 용도로 쓰고, 장비 정보는 해당 도면에서 가져와야 합니다.

쉬운 순서

  1. 목록에서 장비가 나오는 도면만 고릅니다. 예를 들어 수변전 단선결선도, 분전반 결선도, 발전기, ESS(PCS, 배터리 랙), 태양광 인버터, UPS 도면입니다.
  2. 그 도면의 PDF나 사진을 여기에 올려 주세요. 제가 장비를 읽어서 엑셀(.xlsx)로 정리해 드릴게요.
  3. 엑셀 열은 이렇게 잡으면 무난합니다: 장비명 / 기호(TAG) / 용량·규격 / 수량 / 설치 위치 / 도면번호 / 비고.

도면 한 장씩 올리면 정확도가 높아요. 손으로 하실 때도 같은 열로 엑셀에 입력하면 됩니다.

먼저 어떤 장비를 정리하고 싶으세요? (변압기, 분전반, 발전기, ESS 등)

Claude 응답: 사진이 기울어져 있고 글씨가 작아서, 읽히는 제목 기준으로 골랐어요.

Drawing index entries being matched against equipment names

사진이 기울어져 있고 글씨가 작아서, 읽히는 제목 기준으로 골랐어요. 번호는 한 번 확인해 주세요.

1순위 (장비 정보가 바로 나오는 도면)

  • 수변전설비 단선결선도 (EP-02 근처): 변압기, 차단기, 수배전반
  • 수배전반 기기 상세도 (EP-06 근처)
  • 분전반 일람표, 동력분전반 일람표, MDF 일람표 (EP-12~20 근처): 이미 표 형태라 가장 쉬워요
  • 전력간선설비 계통도 (EP-21 근처)
  • 발전기실 확대 설비 평면도 (EP-04 근처)

2순위 (설비별 도면)

  • 태양광 (EP2-01~09): 계통도, 접속반, 인버터 회로도
  • ESS (EP4-01~07): 배치도, PCS(150kW) 회로도, 본전반, 랙 상세도
  • UPS (EP5-01), 전기차 충전설비 (EP6-01~02)
  • 조명기구 상세도 (EP1 계열)

참고도면 쪽

  • 장비일람표-1, -2 (MA-004, MA-005)와 소방 장비일람표 (MF-002)가 있어요. 기계 장비 일람표라서 전기 장비와 겹치는 모터, 판넬이 있는지 확인해 보세요.

먼저 분전반·동력분전반 일람표 도면 한두 장을 가까이서 찍어 올려 주세요. 그걸로 엑셀 양식을 만들어 보여드릴게요.

전기 일람표 부탁해요

Claude 응답: 전기 장비 일람표를 엑셀로 만들었습니다.

명령 2개 실행함, 파일 읽음, 파일 공유함

전기 장비 일람표를 엑셀로 만들었습니다. 시트는 네 개예요.

  • 전기장비일람표: 수변전, 발전기, 기계실 MCC, 태양광, ESS, UPS, 전기차 충전, 자동제어 장비를 규격, 수량, 위치, 도면번호와 함께 정리했습니다.
  • 기계실MCC부하: EP-11~13의 펌프, 공조기, 휀 부하를 정리하고 운전용량을 자동 계산합니다.
  • 분전반일람표: 동력, 조명, 전열 분전반의 전원, 주차단기, 도면번호입니다. MCC반 6개는 계산값과 도면 표기값이 모두 일치했습니다.
  • 확인필요: 도면에서 읽지 못한 항목 목록입니다.

일람표에서 노란색으로 칠한 칸은 글자가 겹치거나 도면에 없어서 수량을 "확인"으로 남긴 항목이에요. 해당하는 것은 VCB, ACB, 콘덴서, APFC 개수, UPS 용량, 전기차 충전기 대수, TR#2 용도입니다. 원도면을 보고 이 칸만 채우시면 됩니다.

조명·전열 분전반 중 LN-7, LE-7, LE-PH 등은 EP-18에서 일부만 읽혀 뺐습니다. 조명기구나 콘센트 같은 기구류는 평면도에서 세어야 해서 이번 일람표에는 넣지 않았어요. 층별 평면도(EP1-xx 등)나 분전반 도면을 더 올려 주시면 이어서 보완할게요.

electric.html을 새로 만들었습니다. 엑셀 시트 세 개(장비일람표, 기계실 MCC 부하, 분전반 일람표)에서 99개 설비를 넣었고, 공조 설비 일지와 같은 방식으로 쓰도록 했어요.

다른 채팅에 있는 기존 electric.html은 제가 볼 수 없어서 합치지 못했습니다. 기존 파일을 여기 올려 주시면 그 파일에 이 내용을 합쳐 드릴게요. 합치기 전에는 이 파일이 기존 것을 덮어쓰니, 기존 기록이 있으면 먼저 백업하세요.

쓰는 순서

  1. 위쪽 버튼에서 분류를 고릅니다: 수변전, 발전기, ESS, 태양광, 기계실 MCC 부하, 분전반(동력), 분전반(조명·전열) 등.
  2. 목록에서 설비를 누릅니다.
  3. 설비 화면에는 탭이 세 개 있습니다.
    • 스펙: 규격, 수량, 위치, 도면번호
    • 사진·영상: 📷 촬영 또는 🖼 앨범
    • 일지: 점검일시(자동), 점검자, 상태(양호/주의/이상), 운전상태·지시값, 관찰·조치 내용

화면 위에는 현재 날짜와 시간이 나오고, 목록 맨 아래에는 백업 zip 내보내기, 보고서 HTML 내보내기, 백업 zip 불러오기 버튼이 있습니다. 폰에서 풀다운이 반응하지 않던 문제를 피하려고 분류와 설비 선택은 풀다운 대신 버튼으로 만들었습니다.

노란색으로 표시했던 "확인" 항목은 수량이 "확인"으로 들어가 있습니다. 백업 zip은 인터넷이 연결된 상태에서만 내보내고 불러올 수 있어요.

GitHub 저장소(gongjo-general)에 올리실 때는 index.html 옆에 electric.html을 같이 올리면 됩니다.
