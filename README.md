# 공조 설비 일지

건물 공조 설비를 점검하면서 **현장 사진·동영상을 설비별로 촬영하고**, 도면 스펙을 확인하고, 운용 중 나타난 문제의 **관찰과 대응을 기록**하는 스마트폰용 웹 일지입니다.

- 사이트: https://atomrobotbuild.github.io/gongjo-general/
- 스마트폰 크롬에서 열고, 메뉴(⋮) → **홈 화면에 추가**를 해 두면 앱처럼 쓸 수 있습니다.
![image](공조날짜.jpg)
## 주요 기능

| 기능 | 설명 |
|---|---|
| 설비 선택 | 1단계(분류) → 2단계(설비)를 큰 버튼으로 선택 |
| 이미지 탭 | 선택한 설비의 사진 촬영, 동영상 촬영, 앨범에서 불러오기 |
| 스펙 탭 | 장비일람표(도면) 기준 설비 사양 표시 |
| 기록 탭 | 날짜별 증상·측정값, 원인·조치·결과 기록 |
| 백업 | 설비별 폴더로 나뉜 압축 파일(zip) 내려받기 |
| 보고서 | 사진·기록·스펙을 파일 하나(html)로 묶어 다른 사람에게 보여주기 |

## 설비 분류

공기조화기(AHU), 전열교환 환기장치, 펌프, 송풍기, 탱크류, 항온항습기, 팬코일유니트, 전기온수기·복사난방, 열교환기(급탕용), GHP, 지열 설비

## 사용 방법

1. 사이트를 열고 **분류**를 누른 뒤 **설비**를 누릅니다.
2. **이미지 탭**에서 사진 설명(선택)을 적고 **사진 촬영** 또는 **동영상 촬영**을 누릅니다.
3. **스펙 탭**에서 도면 사양을 확인합니다.
4. **기록 탭**에서 관찰한 문제와 대응을 날짜와 함께 저장합니다.
5. 다른 설비로 가려면 **설비 바꾸기**를 누릅니다.

## 데이터 저장 위치 (중요)

- 사진, 동영상, 기록은 GitHub가 아니라 **사용 중인 기기의 브라우저 안**에 저장됩니다.
- 그래서 스마트폰에서 찍은 사진은 PC에서 같은 주소를 열어도 보이지 않습니다.
- 브라우저의 **쿠키 및 사이트 데이터를 지우면 사진과 기록이 함께 사라집니다.**
- 폰을 바꾸거나 데이터를 지우기 전에는 반드시 **백업**을 받으세요.

## 백업과 보고서

- **전체 백업 / 선택한 설비만 백업**: `공조설비일지_백업_날짜.zip`이 내려받아집니다. 압축을 풀면 아래 구조가 나옵니다.

  ```
  분류/설비/
     2026-11-16_01_설명.jpg
     2026-11-16_02.mp4
     기록.txt
     스펙.txt
  ```

- **전체 보고서 / 선택한 설비 보고서**: `공조설비일지_보고서_날짜.html` 파일 하나로 만들어집니다. 받은 사람은 파일을 열기만 하면 사진과 기록을 볼 수 있습니다. 동영상은 기본으로 제외되며, 체크하면 포함됩니다(파일이 매우 커짐).
- 내려받은 파일은 PC나 클라우드에 옮겨 보관하세요.

## 스펙 데이터 수정

스펙은 `index.html` 안의 `var D={` 로 시작하는 부분에 들어 있습니다. 설비 이름과 사양 글자를 고치면 화면에 그대로 반영됩니다.

```
["AHU-1 (B1F~1F)","기계실\n급기 12,000㎥/h ..."]
```

줄바꿈은 `\n`으로 씁니다.

## 알아 둘 점

- 스펙은 장비일람표 도면(PDF)에서 옮긴 값입니다. 도면 글자가 흐려 일부 수치에 오차가 있을 수 있으니 **도면과 대조해서 사용**하세요.
- 저장소가 **Public**이라 `index.html`에 들어 있는 설비 스펙은 누구나 볼 수 있습니다. 사진과 기록은 각자의 기기에만 저장되어 공개되지 않습니다.
- 수정한 내용이 폰에 바로 안 보이면 주소 끝에 `?v=숫자`를 붙여서 열어 보세요. (예: `.../gongjo-general/?v=10`)
